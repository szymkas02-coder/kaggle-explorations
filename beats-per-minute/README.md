# Beats Per Minute

The dataset comes from a Kaggle competition focused on predicting beats-per-minute values — likely related to music tempo or physiological heart rate data. The project covers exploratory data analysis of the feature distributions and relationships, followed by training simple regression models as a baseline.

Key finding: initial EDA revealed the feature space and helped identify relevant predictors; simple models established a performance baseline for the competition metric.

This is a learning exercise completed during early ML exploration — not a production-ready solution.
