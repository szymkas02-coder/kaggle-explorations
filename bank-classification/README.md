# Binary Classification with a Bank Dataset

The dataset originates from a Kaggle binary classification competition using bank customer data — likely predicting customer churn or a similar outcome. The work includes thorough EDA of customer attributes, feature preparation, and training baseline classifiers such as logistic regression and tree-based models.

Key finding: EDA uncovered class imbalance and key correlated features; the prepared model achieved a solid baseline score on the competition leaderboard.

This is a learning exercise completed during early ML exploration — not a production-ready solution.
