# kaggle-explorations

A collection of exploratory notebooks completed during early ML learning. Focus is on EDA and baseline models rather than production-ready solutions.

## Projects

- **[beats-per-minute](beats-per-minute/)** — Regression task predicting beats-per-minute values; covers EDA and simple baseline models.
- **[bank-classification](bank-classification/)** — Binary classification on bank customer data; explores churn-like prediction with feature analysis and baseline classifiers.
- **[road-accidents-risk](road-accidents-risk/)** — Classification task predicting road accident risk from environmental and infrastructure features.
- **[flood-prediction](flood-prediction/)** — Flood event prediction using hydrological and meteorological data, with iterative model improvement across three notebooks.
