# Flood Prediction

The dataset is from a Kaggle competition on predicting flood events, containing hydrological and meteorological features. The project progresses through EDA, baseline model development, and iterative improvement to find the best-performing configuration — documented across three notebooks.

Key finding: feature engineering on weather-related variables improved model performance meaningfully over the naive baseline.

This is a learning exercise completed during early ML exploration — not a production-ready solution.
